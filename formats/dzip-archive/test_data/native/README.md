# Native Dzip test corpus

These deterministic fixtures were generated by `dzip.exe`, not by dzip-archive.

- `codecs.dcl` covers DZ common references, zlib, bzip, LZMA, copy, zero, and legacy flags.
- `ranges.dcl` covers aligned multi-volume output and sliced DZ inputs.
- `tiny.dcl` covers empty, one-byte, and two-byte DZ inputs without COMBUF.
